# Contribuindo com o GelatoStock

- **Bugs:** abra uma issue com o comportamento esperado, o observado, passos para reproduzir e versão do Android. Use dados fictícios; não envie credenciais, bancos ou backups reais.
- **Melhorias:** descreva o problema e a proposta em uma issue. Discuta mudanças maiores antes de implementá-las.
- **Pull requests:** envie alterações focadas, explique o resultado e informe as verificações realizadas. Para mudanças funcionais, inclua testes proporcionais ao risco. Consulte os comandos de build no [README](README.md).

Preserve o funcionamento offline, a integridade do estoque, o histórico e a compatibilidade dos dados. Alterações de banco exigem migrações explícitas sem perda de dados; alterações de backup devem manter uma estratégia de compatibilidade.
